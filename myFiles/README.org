# myConfig
Basic configuration files to set up my personal computer after a clean installation of S.O.
There are two different files in progress, one to set up an Ubuntu machine, and another for a CachyOs machine

## Files

**current.gitignore** A generic .gitignore file to ignore most of nuisance files that may occur in my projects.\
**current.Rpackages.sh** Predefined packages to install after a clean OS installation.\
**current.emacs.el** Personal configuration of emacs.\

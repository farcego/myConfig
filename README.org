# myConfig
Basic configuration files to set up my personal computer after a clean
installation of S.O.  There are two different files in progress, one
to set up an Ubuntu machine, and another for a CachyOs machine. The
rrst of the configuration files should be OS agnostic (as long as it
is Linux OS).

* Folders
** distros
- process-cachyOS.org
- process-ubuntu.org
** emacs
- current.emacs.el: Personal configuration of emacs
** git
- current-gitconfig
- current.gitignore: A generic .gitignore file to ignore most of non needed/shareable files that may occur in my projects.
** R
- currentRbuildignore
- current.Renviron
- current.Rpackages.sh: Predefined packages to install after a clean OS installation.
